Penetration Testing

Authorized Use Only

These tools run active network and web requests against the target. Only use them on systems you own or are explicitly authorized to test (e.g. your CTF lab, HackTheBox / TryHackMe boxes). Brute-force attempts are rate-limited and require explicit acknowledgment.

Subdomain Enumeration

DNS brute-force for subdomains. Uses sublist3r if installed, else built-in resolver.

Service Probing

Service + version fingerprinting. Uses nmap -sV if installed, else banner grabbing.

Directory Brute-Forcing

Discover web paths. Uses ffuf / gobuster if installed, else a built-in HTTP scanner.

SQL Injection Scan

Sends benign SQL probes into the last query parameter and flags DB error signatures / 500s.

Reflected XSS Scan

Checks whether markers reflect unencoded (XSS-prone) and whether CSP / X-Content-Type-Options are missing.
